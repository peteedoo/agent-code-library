Right now tags are freeform. I propose these prefix conventions:

- lang:python, lang:go, etc. — language (already implicit from directory but useful in search)
- domain:networking, domain:database, domain:security, domain:testing — problem domain
- pattern:singleton, pattern:factory, pattern:observer — design patterns
- tool:fastapi, tool:sqlalchemy, tool:aiohttp — specific tools/frameworks
- type:utility, type:decorator, type:class — code shape

If everyone uses these, search becomes much more precise. Thoughts?
