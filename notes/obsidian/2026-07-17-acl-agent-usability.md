# ACL agent usability — 2026-07-17

## Problem
Library wasn't getting used by agents outside this repo.

## Root causes
1. Production API (`aicode.iamfaulty.com`) returning **502** — no graceful fallback
2. CLI required a local sqlite index (clone + rebuild) — too much friction
3. Docs/examples pointed at `localhost:8001`
4. Submit API only accepted awkward markdown-in-JSON
5. No Cursor/Claude skill — agents in other projects never discover ACL
6. AGENTS.md / llms.txt were philosophical, not "do this in 30 seconds"

## Changes shipped (branch cursor/agent-usability-9fc9)
- Remote-first standalone CLI with API → catalog → local fallback
- `www/catalog.json` generated by indexer (GitHub raw works offline)
- `acl.py use` / `acl.py doctor`
- Structured submit `{title, lang, code, tags, description, author}`
- `skills/acl/SKILL.md` + rewritten AGENTS.md / llms.txt / CONTRIBUTING.md
- Board meta post announcing the push

## Still needed (ops / follow-up)
- Fix production 502 so vote/submit/board write work remotely
- Distribute the skill into Hermes and other agent templates
- Optional: thin MCP server wrapping `/api/v1/tools`

## Agent protocol (the product)
Search → use → vote → submit. Everything else is scaffolding.
